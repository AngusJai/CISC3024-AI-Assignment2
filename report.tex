\begin{abstract}
\textbf{Thesis:} a discriminative variational Bayesian last layer (D-VBLL; Harrison, Willes, and Snoek, ICLR 2024) puts a Gaussian posterior on the last-layer weights of a clothing classifier.
On Fashion-MNIST it matches softmax MAP on accuracy, likelihood, and on which errors it ranks as uncertain.
Its calibration error is lower than an unscaled softmax, but one temperature fit on the validation set calibrates the softmax further.
Gaussian naive Bayes on pixels fails; linear discriminant analysis on the same CNN features is close in accuracy and worse as a probability model.
The learned weight variance stays far below the prior, so that discriminative posterior stays close to a point estimate.
The generative VBLL from the same paper, which applies Bayes' rule to class-conditional Gaussians on the features, is the head that separates MNIST from clothes.
Neither head detects low-contrast shift, and refusing low-confidence predictions does not repair rotation.
Search, implementation, experiments, and this report were done by a Cursor agent under a standing instruction that I would not hand-write code.
\end{abstract}

\section{Algorithm Description}
\label{sec:algo}
\paragraph{Model}
A network with weights $\theta$ maps an image $x$ to a feature vector $\phi(x,\theta)\in\mathbb{R}^{D}$.
Class logits are a noisy linear readout. For a last-layer matrix $W$ whose $k$-th row is $w_k$,
\begin{equation}
p(y\mid x,W,\theta)=\mathrm{softmax}(z),\qquad
z = W\phi(x,\theta)+\varepsilon,
\label{eq:disc}
\end{equation}
with zero-mean Gaussian noise $\varepsilon$.
This is Bayesian logistic regression on learned features.
The prior on each row is isotropic Gaussian, $p(w_k)=\mathcal{N}(0, s^{2}I)$, with the authors' fan-in scaling $s^{2}=2/D$.
Exact softmax marginalization is intractable, so training uses a variational posterior that factorizes across classes,
$q(w_k)=\mathcal{N}(m_k,\mathrm{diag}(v_k))$.
Diagonal covariances drop cross-class correlation and make every loss term linear in $D$.

\paragraph{Training bound}
Stochastic variational inference~\cite{hoffman2013svi} maximizes a lower bound on the log marginal likelihood.
For one example with label $y$, Theorem~2 replaces the expected log-softmax by
\begin{equation}
m_y^{\top}\phi
- \log\sum_{k}\exp\!\Big(m_k^{\top}\phi
+ \tfrac12\big(\phi^{\top}\mathrm{diag}(v_k)\phi+\sigma_k^{2}\big)\Big).
\label{eq:bound}
\end{equation}
The extra $\tfrac12\phi^{\top}\mathrm{diag}(v_k)\phi$ term is the Jensen gap: uncertain weights inflate every logit before the log-sum-exp, which stops the bound from behaving like an over-confident point estimate.
The mini-batch loss I minimize is the negative of that bound, plus $(1/T)\,\mathrm{KL}(q(W)\,\|\,p(W))$, minus a $(1/T)$ inverse-Wishart-style penalty on the noise variances $\sigma_k^{2}$.
$T$ is the number of training images.
Feature weights $\theta$ get an ordinary Gaussian prior, implemented as AdamW weight decay.
Here $\theta$ denotes the CNN weights, and $\varepsilon$ is the logit noise in Equation~\eqref{eq:disc}.
The last-layer parameters are not weight-decayed, because the KL term is already their regularizer.
This is the paper's ``full training'' objective, not a post-hoc Laplace approximation and not Bayes-by-Backprop on every layer~\cite{blundell2015weight}.

\paragraph{Prediction}
The posterior predictive probability is the expectation of the softmax under $q(W)$.
That expectation has no closed form for the discriminative model, so I draw logit samples
\begin{equation}
z^{(s)}\sim\mathcal{N}\!\big(m^{\top}\phi,\;\mathrm{diag}(\phi^{\top}S\phi+\sigma^{2})\big)
\label{eq:pred}
\end{equation}
and average $\mathrm{softmax}(z^{(s)})$.
Test metrics use 32 samples.
Out-of-distribution scores use the maximum predictive probability~\cite{hendrycks2017baseline}.

\paragraph{What is Bayesian here}
Write the four objects separately, because a pattern-recognition classifier is the posterior predictive, not the training loss.
The prior is $p(W)=\prod_k\mathcal{N}(w_k;0,s^{2}I)$.
The likelihood is the softmax in Equation~\eqref{eq:disc}.
The variational posterior $q(W)$ stands in for $p(W\mid\mathrm{data})$, and the KL term keeps it from ignoring the prior.
The reported class probability is the posterior predictive $\mathbb{E}_{q(W)}[\mathrm{softmax}(W\phi)]$, not a point $W$.
A softmax MAP baseline uses the same features and the same likelihood, but one weight matrix.
Gaussian naive Bayes and linear discriminant analysis, used later as controls, are the generative version of this story: they put Gaussians on $\phi$ or on the pixels and apply Bayes' rule for $p(y\mid x)$.
D-VBLL is the discriminative version. It never builds $p(x\mid y)$.

\paragraph{Generative VBLL}
The same paper also specifies a generative classifier.
Class $k$ owns a Gaussian mean $\mu_k$ in feature space, with prior $\mathcal{N}(0, s^{2}I)$ and variational posterior $\mathcal{N}(\bar\mu_k,\mathrm{diag}(v_k))$.
A shared diagonal noise covariance $\Sigma$ gives the marginal
$p(\phi\mid k)=\mathcal{N}(\bar\mu_k,\Sigma+\mathrm{diag}(v_k))$.
With a uniform class prior, which is exact on this balanced training split, Bayes' rule is a softmax of those log densities:
\begin{equation}
p(y\mid\phi)=\mathrm{softmax}_y\big(\log p(\phi\mid y)\big).
\label{eq:gvbll}
\end{equation}
Theorem~3 trains this model with a sampling-free bound. The predictive distribution is closed form, so there is no Monte Carlo step.
I call this head G-VBLL. It is the deep analogue of the LDA control.
Bayes' rule for this head is the ordinary posterior over the class:
\begin{equation}
p(y\mid\phi)
= \frac{p(\phi\mid y)\,p(y)}{\sum_{c} p(\phi\mid c)\,p(c)}.
\label{eq:bayes}
\end{equation}
The prior is $p(y)=1/10$, uniform because the training split is balanced.
The likelihood is the class-conditional Gaussian $p(\phi\mid y)=\mathcal{N}(\bar\mu_y,\Sigma+\mathrm{diag}(v_y))$.
The posterior is the left-hand side, $p(y\mid\phi)$, which is what the classifier reports.
D-VBLL does not use Equation~\eqref{eq:bayes}.
Its prior is $p(W)$, its likelihood is the softmax $p(y\mid x,W,\theta)$, and its posterior is $q(W)$ standing in for $p(W\mid\mathrm{data})$.
The class probability is then the posterior predictive, an average of that likelihood under $q(W)$.

The layout is:
\begin{itemize}
  \item \texttt{models/vbll.py} --- diagonal D-VBLL (Theorem~2, Monte Carlo softmax) and G-VBLL (Theorem~3, closed-form Bayes rule).
  \item \texttt{models/backbone.py} --- shared CNN. Three conv stages, batch-norm, global average pool, 128-d features. About $1.58\times 10^{5}$ parameters.
  \item \texttt{models/classifier.py} --- \texttt{map}, \texttt{vbll}, or \texttt{gvbll}. Weight decay applies to the backbone only when the head is Bayesian.
  \item \texttt{data\_utils.py} --- Fashion-MNIST / MNIST tensors, shared augmentation, pixel-space corruptions.
  \item \texttt{train.py}, \texttt{evaluate.py}, \texttt{metrics.py}, \texttt{figures.py}.
  \item \texttt{run\_all.py}, \texttt{run\_ablation.py}, \texttt{run\_upgrades.py}.
  \item \texttt{extra\_analysis.py}, \texttt{upgrade\_analysis.py}. Neither script retrains a finished checkpoint.
\end{itemize}
The training step, in the form that \texttt{self\_check()} tests, is:
\begin{quote}
\small
$\phi \leftarrow \mathrm{backbone}(x)$.\\
$\mu_k \leftarrow m_k^{\top}\phi$,\quad $v_k \leftarrow \phi^{\top}\mathrm{diag}(v_k)\phi+\sigma_k^{2}$.\\
$\mathrm{bound} \leftarrow \mu_y - \log\sum_k\exp(\mu_k+\tfrac12 v_k)$.\\
$\mathrm{loss} \leftarrow -\mathrm{mean}(\mathrm{bound})+(1/T)\,\mathrm{KL}(q\|p)-(1/T)\,\log p(\sigma^{2})$.
\end{quote}
Before training, \texttt{self\_check()} builds an $8\times 4$ random batch and checks three facts: the loss is finite and back-propagates; the bound matches a hand-expanded log-sum-exp; multiplying the features by four increases logit variance.
That check is the implementation test.
It does not use Fashion-MNIST accuracy as a substitute for the formula.

Practical settings follow the paper and the authors' diagonal parameterization rather than a new variant.
The prior variance is $2/D$.
Weight standard deviations are initialized near $1/D$.
The KL is scaled by $1/T$ in the main runs.
I did not import the \texttt{vbll} library; the module is a direct implementation of the bound above so the loss can be read against Equation~\eqref{eq:bound}.

\section{Experiment Settings and Results}
\paragraph{Task}
In-distribution data are Fashion-MNIST clothing images, $28\times 28$ greyscale, 10 classes~\cite{xiao2017fashion}.
The official training set is split once, with seed 0, into 54{,}000 training images and 6{,}000 validation images.
The 10{,}000 official test images are used only for the tables below.
MNIST digits are a far out-of-distribution set~\cite{lecun1998gradient}: same resolution, different pattern family.
Both datasets are normalized with the Fashion-MNIST training mean $0.286$ and standard deviation $0.353$.

\paragraph{Protocol}
The three heads share the CNN, the augmentation (horizontal flip and a random crop after 2-pixel padding), AdamW at learning rate $10^{-3}$, cosine decay, batch size 128, and 12 epochs.
Backbone weight decay is $10^{-4}$.
MAP, D-VBLL, and G-VBLL use seeds $\{0,1,2\}$. All runs are on Apple MPS (PyTorch 2.14).
Validation probabilities for D-VBLL use 16 logit samples; the test tables use 32.
Means for all three heads are over three seeds.
Calibration is expected calibration error with 15 bins~\cite{guo2017calibration}.

\paragraph{Controls a probability model still has to pass}
A lower ECE than softmax is not, by itself, evidence that the posterior did the work.
Three controls use the same test set and do not change the trained CNN.

Temperature scaling~\cite{guo2017calibration} divides the MAP logits by a scalar $T$ fit on the 6{,}000 validation images by minimizing NLL.
It does not change the predicted class.
On the three MAP seeds, $T$ is $1.114$, $1.088$, and $1.119$.
Test ECE falls to a mean of $0.0054$, below D-VBLL's $0.0074$, and mean NLL is $0.197$.
The ECE gap in Table~\ref{tab:clean} is therefore mostly a temperature, which matches the later finding that $q(W)$ has concentrated.

Gaussian naive Bayes on raw pixels, with an independent Gaussian per pixel and per class, reaches accuracy $0.579$, NLL $7.63$, and ECE $0.419$.
The independence assumption does not describe a garment.
Shrinkage linear discriminant analysis on the 128-d features of the seed-0 MAP network is the classical shared-covariance Bayes classifier on the same representation.
It reaches accuracy $0.917$, close to the discriminative heads, but NLL $0.544$ and ECE $0.063$.
The CNN features carry the class.
The softmax and D-VBLL heads are what make the probabilities sharp.

Ranking is a separate question from calibration.
Using confidence to detect the model's own mistakes, mean AUROC is $0.922$ for MAP, $0.924$ for D-VBLL, and $0.920$ for G-VBLL.
Pixel naive Bayes is at chance on this ranking ($0.510$); LDA on the CNN features reaches $0.900$.
Keeping the most confident $90\%$ of the clean test set raises accuracy to $0.968$ (MAP), $0.967$ (D-VBLL), and $0.967$ (G-VBLL).
Figure~\ref{fig:risk} shows the risk-coverage curves lying on top of each other.
D-VBLL does not rank errors better than softmax once the posterior has collapsed.
All three heads are still useful as reject options: the bottom decile of confidence contains a disproportionate share of the mistakes.

\paragraph{Why the Bayesian head stays close to MAP}
After training at KL weight $1/T$, the mean diagonal variance of $W$ is about $4.9\times 10^{-4}$.
The prior variance is $2/D=0.0156$, roughly thirty times larger, so the posterior has concentrated.
The KL itself is about $2.3\times 10^{3}$; divided by $T=54000$ it contributes only a few hundredths to the loss, which is enough to regularize but not enough to keep the prior's uncertainty.
Figure~\ref{fig:norm} then has a simple shape for both models: predictive entropy falls as $\|\phi\|$ grows.
Large features produce large mean logits, and the quadratic variance term is too small to cancel that peak.
This is the opposite of a distance-aware uncertainty method, and it matches the modest ECE gap in Table~\ref{tab:clean}.

\label{fig:norm}
\end{figure}

\paragraph{KL-weight ablation}
The $1/T$ factor is a hyperparameter of the ELBO estimator, not a constant of nature.
D-VBLL was retrained at $10/T$ and $100/T$ for seeds 0 and 1.
Table~\ref{tab:kl} reports means.
A single seed had made $10/T$ look like an OOD improvement ($0.869$ versus $0.825$).
The second seed removes that claim: mean AUROC at $10/T$ is $0.844$, which does not beat $1/T$ ($0.856$).
$100/T$ does raise mean AUROC to $0.913$, and it also raises ECE to $0.094$ and NLL to $0.288$.
Accuracy stays at $0.927$--$0.928$.
The KL term is alive. A moderate increase does not buy out-of-distribution detection, and a large increase buys it by making the predictive distribution less sharp on the clean test set.

\paragraph{Prior scale does not uncollapse the posterior}
The prior variance is $\mathrm{prior\_scale}\times 2/D$.
I retrained seed-0 D-VBLL at scales $0.1$, $1$, and $10$, so the prior variance runs from $0.0016$ to $0.156$.
Mean posterior variance stays between $2.5\times 10^{-4}$ and $5.4\times 10^{-4}$ in all three runs.
Widening the prior does not restore the uncertainty the KL term at $1/T$ is too weak to protect.
Entropy and MNIST AUROC both fall as the prior widens: AUROC is $0.883$, $0.825$, and $0.791$.
The KL multiplier, not the prior scale, is the knob that moved the predictive distribution.

\paragraph{Monte Carlo sample size}
D-VBLL predictions average softmaxes.
On the three seeds, 8, 32, and 64 samples agree to about $0.001$ in accuracy and NLL, and ECE stays inside $0.007$--$0.008$.
The published tables use 32 samples. Eight would have been enough on this dataset.

\paragraph{Shirt versus T-shirt}
Headline ECE near $0.01$ is an average over easy classes.
On shirt images alone, accuracy is $0.776$ (MAP), $0.767$ (D-VBLL), and $0.768$ (G-VBLL), and the class-conditional ECE is about $0.074$, $0.075$, and $0.049$.
About $10\%$ of shirts are predicted as T-shirts under every head.
G-VBLL is less confident on shirts (mean confidence $0.79$ against $0.84$ for MAP), which is why its shirt ECE is lower, not because it names them more often.
The overlap is in the labels and the silhouette.

\paragraph{Rejection under shift}
Figure~\ref{fig:sel} drops the least confident $10\%$.
That helps on clean images and does not help once the input is shifted.
At $60^{\circ}$ rotation, accuracy among the kept $90\%$ is $0.123$ (MAP), $0.122$ (D-VBLL), and $0.116$ (G-VBLL), against a full-set accuracy of about $0.118$.
Under low contrast the kept slice is $0.174$ (MAP), $0.241$ (D-VBLL), and $0.119$ (G-VBLL), against full-set accuracies of $0.178$, $0.237$, and $0.125$.
Confidence is a reject option when the test distribution matches training. It is not a detector for a preserved silhouette with the wrong intensity or the wrong angle.

\section{What I Have Learnt from This AI Assignment}
\begin{itemize}
  \item The useful constraint was the brief itself: probability or Bayes, recent, and not a repeat of FasterNet. Once that was stated, the agent could reject a fast CNN and look for a last-layer posterior with a checkable formula.
  \item A Bayesian classifier is defined by the predictive distribution, not by the word ``uncertainty'' in the README. Here that distribution is an average of softmaxes under $q(W)$. The self-check on Equation~\eqref{eq:bound} mattered more than the first epoch's accuracy.
  \item Matching accuracy is a real result, and it is not the whole probability question. D-VBLL at $1/T$ ties MAP on accuracy, NLL, Brier score, and error ranking. The ECE edge over unscaled softmax disappears once the softmax has a validation temperature. I should not describe D-VBLL as a better calibrated classifier than temperature scaling.
  \item Posterior variance can collapse, and widening the prior does not undo it. The prior said $0.016$ at the default scale; training at $1/T$ kept the posterior variance below $6\times 10^{-4}$ even when that prior was widened or narrowed by a factor of ten. A second seed also removed a false OOD win for the $10/T$ KL weight. Only $100/T$ raises MNIST AUROC, and it does so by making clean probabilities less sharp.
  \item A Bayes classifier still needs a representation. Pixel naive Bayes scores $0.579$ because garment pixels are not independent Gaussians. LDA on the CNN features jumps to $0.917$, and the discriminative heads then cut NLL from $0.544$ to $0.200$. The modern part is the feature map; the last-layer posterior is a small adjustment on top.
  \item The generative head applies Bayes' rule, and it is the one that moves out-of-distribution detection. G-VBLL's MNIST AUROC is $0.910$ with almost no seed spread. It pays for that with a higher clean NLL and ECE than D-VBLL.
  \item Confidence is a reject option only on the training distribution. Dropping the least confident $10\%$ lifts clean accuracy to about $0.967$ and does nothing under $60^{\circ}$ rotation or low contrast. Shirt ECE stays near $0.07$ while the headline ECE is near $0.01$. Eight Monte Carlo samples match sixty-four on this test set.
  \item Out-of-distribution AUROC needs more than one seed. MAP's three seeds still spread by about nine points. G-VBLL's three seeds differ by $0.005$. A single-run bar chart would have picked a winner that the next seed does not support.
\end{itemize}

\section{Conclusion}
D-VBLL is a recent Bayesian classifier that an agent can implement from a variational bound and test on clothing images in one afternoon.
With the paper's $1/T$ KL weight it reproduces the softmax baseline's accuracy and slightly improves unscaled calibration.
A validation temperature on that softmax calibrates further, and a classical LDA head on the same features is close in accuracy but worse in NLL.
D-VBLL does not detect digit images, because the approximate posterior concentrates. Widening the prior leaves that concentration in place. Only a much larger KL weight raises MNIST AUROC, and it does so by hurting clean NLL and ECE.
G-VBLL, the generative classifier in the same paper, is the head that applies Bayes' rule to the features. Its MNIST AUROC is $0.910$ and stable across seeds, with a small cost in clean likelihood and calibration.
Refusing the least confident tenth of the test set helps only when the images still look like the training set. Accuracy on this network stays near $0.93$.
